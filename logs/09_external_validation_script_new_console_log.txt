> # ==============================================================================
> # Script: 09_external_validation.R
> # Purpose: Test the panels on an independent cohort that shares no samples and
> #          no microarray platform with the compendium they were derived on.
> #
> # THE VALIDATION COHORT
> #   GSE25099, titled "Expression data from 57 patients with oral cancer and 22
> #   normal persons". Its normals are independent donors, stated in the series
> #   title, which makes it the right comparison for a panel trained on donor
> #   normals. The deposited platform is GPL5175, the Affymetrix Human Exon 1.0
> #   ST Array, transcript (gene) version. The free-text summary on the GEO page
> #   names the Human Gene 1.0 ST Array instead. GPL5175 is the accession the
> #   series is filed under and is what the series matrix is indexed by, so the
> #   annotation used here is GPL5175.
> #
> # WHY THE DIFFERENT PLATFORM IS USEFUL RATHER THAN A NUISANCE
> #   Two platforms measure the same gene on different probe chemistry, so their
> #   absolute values are not comparable and neither are their normalizations. A
> #   panel that still works across that gap is carrying biological signal rather
> #   than a property of one array design.
> #
> # HOW THE GAP IS CROSSED
> #   Each sample is converted to within-sample gene ranks before anything is
> #   fitted. A rank inside one array is unchanged by any transformation that
> #   preserves order, so array offset, array scale and platform normalization all
> #   drop out. Only the relative ordering of genes inside a sample survives, and
> #   that is what the model sees on both sides. No batch correction is applied
> #   here and none is needed.
> #
> #   Ranks are computed over all genes shared between the platforms and only then
> #   subset to the panel, so a gene's rank means its position in the whole
> #   transcriptome rather than its position among a handful of panel genes.
> #
> # WHY GENES ARE MATCHED ON ENTREZ ID AND NOT ON SYMBOL
> #   The compendium symbols come from a current hgu133plus2.db build. The GPL5175
> #   annotation table was deposited in 2007. HGNC has renamed genes in between,
> #   so the same locus carries a different symbol on the two sides. Two of the
> #   seven genes in the C_DONOR panel are affected. LINC02487 is LOC441178 in the
> #   older annotation and CFAP251 is WDR66. Matching symbol strings would drop
> #   both and would report the loss as an absent gene rather than as a rename.
> #   Entrez Gene ID is stable across both annotation vintages, so the match runs
> #   on Entrez. The compendium side takes its Entrez ID from the same probe that
> #   step 03 chose for each symbol, so no alias guessing is involved.
> #
> # WHICH PANELS ARE TESTED
> #   Both the stability panel from step 05 and the minimum panel from step 07,
> #   for the run named in BEST_RUN. The minimum panel is small by construction,
> #   so how much it loses relative to the stability panel is part of the result.
> #

> # OUTPUT  results/external_validation.csv, results/external_confusion.csv,
